# Project Overview: Instant Typing

**Instant Typing** (`instanttyping.com`) is a high-performance, client-side typing speed and accuracy testing web application. It features a dark-themed aesthetic with interactive 3D and canvas visual elements, multilingual internationalization across 8 languages, and flexible typing modes (Time, Words, Quote, Custom). It provides real-time WPM, accuracy, error metrics, consistency scoring, weak-key diagnosis, and client-generated PNG certificates without requiring user accounts or backend infrastructure.

## Tech Stack
- **Framework:** Astro 7.3.3 (Static Site Generation / client-side islands)
- **Language:** TypeScript 5.9.0
- **Styling:** Tailwind CSS 4.3.3 via `@tailwindcss/vite`, CSS Custom Properties
- **Motion & Audio:** Lenis 1.3.26 (smooth scroll), Anime.js 4.5.0, Tone.js 15.1.22, Sonic Flow 1.0.2
- **Graphics:** CSS 3D Transforms, HTML5 Canvas 2D, WebGL Shaders (Moonlit background)
- **Typography:** Geist Variable, JetBrains Mono Variable, Inter Variable
