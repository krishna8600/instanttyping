# AI Workflow Rules

1. **Step-by-Step Discipline:** Plan before modifying. Research first, present exact specs, and obtain user approval before executing code changes.
2. **Read-Only Audits Stay Read-Only:** Do not create, modify, or delete project source files during an audit or planning phase.
3. **Task Isolation:** Complete one unit at a time. Validate each unit against the verification checklist before moving to the next.
4. **Fact-Checking & Precision:** Quote actual line numbers, exact variable names, and real file paths. Never guess or hallucinate nonexistent APIs.
5. **Progress Tracking:** Update `progress-tracker.md` after completing each discrete milestone or task unit.
